# Performance documents

Earlier versions of this repository published multi-hundred-percent ROI tables,
named “conviction” insiders (`AAPL_CEO_Conviction`, `Insider_NVDA_2026_3`, …),
and fake accession numbers such as `0000320193-26-99999CEO`.

Those rows were **generated by a seeded random function** in
`IndustryOrganizer.collect_and_organize_trades`. They were **not** SEC Form 4
filings.

They have been removed. The collector now downloads official EDGAR Form 4 XML
only. Strategy methodology remains in [`STRATEGIES.md`](STRATEGIES.md).

To produce a backtest from official data:

```bash
export SEC_USER_AGENT="YourAppName contact@yourdomain.example"
python main.py collect --year 2026
python main.py backtest --strategy conviction
```
